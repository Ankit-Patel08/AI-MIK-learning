NORTHSTAR TECHNOLOGIES — SAMPLE POLICY KNOWLEDGE BASE
====================================================

This folder contains six fictional policy documents for learning and testing a
Retrieval-Augmented Generation (RAG) pipeline.

Files:
1. HR_Employee_Policy.txt
2. IT_Acceptable_Use_and_Security_Policy.txt
3. Information_Data_Privacy_Policy.txt
4. Finance_Expense_and_Reimbursement_Policy.txt
5. Procurement_and_Vendor_Management_Policy.txt
6. Business_Continuity_and_Incident_Response_Policy.txt

Each document contains multiple named sections and policy-specific details.
All company names, limits, timelines, and procedures are fictional examples.
They are not legal, HR, security, finance, or compliance advice.

RAG practice suggestion:
- Load every .txt file in this folder.
- Preserve the filename as metadata for each chunk.
- Split by SECTION headings first, then split long sections into smaller chunks.
- Store each chunk's text, source filename, section heading, and embedding.
